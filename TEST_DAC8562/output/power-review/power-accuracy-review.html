DAC8562 전원·출력 정확도 검토 / STM32H747 별도 SMA 회로

2026-10-12 · 저장된 최종 프로젝트와 공식 데이터시트 대조 · 원본 설계는 변경하지 않음

검토서와 별도 회로 초안입니다. 원본 PCB의 제작 승인이 아닙니다. STM32H747 모듈은 MCU 본체를 포함하지 않고 외부 MCU DAC 신호를 받습니다. PCB 합치기·배선은 수행하지 않았습니다.

2. TPS65131 전원

현재 저항값의 공칭 레일은 +11.97231V / -12.13000V입니다. VFBP, VFBN, VREF의 데이터시트 끝값과 분압 저항 1%를 독립적으로 조합하면 정적 계산 범위는 +11.527~+12.431V, -12.766~-11.503V입니다. 실제 기동/리플/온도 파형을 계산한 값은 아닙니다.

입력 5V와 L1/L2=4.7µH, VREF의 220nF, PSP/PSN=GND는 기본 권장 구성에 부합합니다. PSP/PSN을 GND로 둔 연속 PWM 모드는 유지합니다. ENP/ENN을 VIN_CTRL에 묶었으므로 레일 순서와 전원 양호 신호는 제공하지 않습니다. soft-start 약 1ms는 스위치 전류 제한의 램프 시간이며 출력의 동시 안정화 시간이 아닙니다.

C1 계산값은 7.67pF, C2는 7.50pF이므로 7.5pF C0G를 검토합니다. R5=100Ω와 C8=100nF의 시정수는 10µs입니다. 입력 상승률이 275mV/µs 이상인 빠른 핫플러그에서는 §8.2.3.2에 따라 R5를 저 DCR 페라이트 비드로 변경하고 안정성을 확인합니다. 모든 입력/출력 MLCC는 실제 DC 바이어스 유효 용량으로 평가합니다. 스위치 한계 1.95A를 출력 공급 가능 전류로 해석하지 않습니다.

3. LP2985와 DAC 전원 여유

LP2985의 IN/EN은 +12V 레일입니다. 입력 5V에서 바로 5V를 만드는 연결이 아니므로 정상 상태의 dropout은 주된 문제가 아닙니다. C14 BYPASS=10nF는 유지합니다. C15=4.7µF 25V X5R은 부품 리비전과 바이어스·온도·공차·ESR 확인을 조건으로 유지할 수 있습니다. legacy 칩 최소 유효 COUT는 2.2µF, new 칩은 1µF입니다. 입력 C13의 유효 용량도 확인합니다. new 칩의 EN 허용 범위는 16V이므로 현재 +12V 직결 자체가 과전압 오류는 아닙니다.

legacy 표준 등급은 1~50mA·전체 온도에서 5V±3.5%인 4.825~5.175V, new 칩은 ±1%인 4.95~5.05V입니다. 5V까지 출력하는 DAC에 충분한 양의 레일 여유가 항상 있다고 볼 수 없습니다. 5mA에서 LDO 손실은 약 34.9mW이지만 150mA에서는 약 1.05W가 됩니다. MCU/릴레이를 이 LDO에 추가로 연결하지 않습니다.

정확도 개선 후보 TPS7A4901은 5.25V로 설정할 수 있지만 SOT-23-5 직접 대체품이 아닙니다. 총 허용 오차 2.5%에 분압 0.1%를 보수적으로 더한 약 2.7%를 사용하면 DC 5.108~5.392V로 5.5V 이내입니다. 이는 기동 오버슈트를 포함하지 않으며 소자·분압 공차와 기동 최고값을 재확인해야 합니다. 새 LDO의 NR/SS, FB, 출력 MLCC와 역류 조건을 새 데이터시트대로 설계합니다. LP2985 그라운드를 들어 올려 5.25V를 만드는 방식은 채택하지 않습니다.

4. DAC8562T 출력 정확도

현재 이상적 전달식은 Vout=(100k/24.9k)*(Vdac−Vref), DAC 내부 gain=2입니다. 공칭 코드 끝점은 -10.04016~+10.03985V이고 SMA에서 1LSB는 0.306mV입니다. 16비트 분해능과 절대 출력 정확도는 다릅니다.

2점 이상 채널별 보정, 필요 시 다점 LUT 및 온도 보정을 적용합니다. 1% 정착 시간 12.94µs는 16비트 정착 시간 보증이 아닙니다. precision 용도는 DAC8562T 경로를 우선 사용합니다.

현재 DAC 출력의 입력 저항 경로는 24.9kΩ+100kΩ 부하입니다. DAC 출력 임피던스의 전형값 5Ω을 단순 사용하면 5V 부근에서 SMA 환산 약 0.80mV의 부하 영향이 생길 수 있습니다. 5Ω은 중간 코드에서의 전형값이지 전체 코드의 최대 보증값이 아니므로 이 값은 예시이며 총 오차 보증에 넣지 않습니다. 더 작은 오차에는 DAC 출력 버퍼 추가, 외부 저드리프트 기준전압, 저항 정합 향상을 별도 검토합니다.

5. DAC 초기화 / 전원 차단

  1. 하드웨어 출력 mute 유지. DAC 전원이 안정되기 전 MCU 출력은 분리/Hi-Z.
  2. 양·음 레일과 DAC AVDD의 정상 상태를 확인. 고정 1ms 지연만으로 판단하지 않음.
  3. 전체 소프트웨어 리셋 0x280001.
  4. 기준전압 OFF 상태에서 두 채널을 0x8000으로 기록 및 갱신: 0x1F8000.
  5. 내부 기준전압 ON: 0x380001. 이 명령은 gain=2도 선택. 필요 시 0x020000으로 두 gain을 명시.
  6. C17/C24가 연결된 기준전압과 출력의 정착 확인 후 mute 해제.
  7. 보정·범위 제한된 명령으로 운전. MCU 재부팅/통신 실패 시 하드웨어 mute. CLR을 0V 출력 용도로 사용하지 않음.

정상 종료는 먼저 mute, 실제 스위치/접점 해제 이후 레일을 내립니다. Brownout 후 POR은 AVDD<0.7V가 1ms 이상 유지되어야 보증됩니다. 0.7~2.2V로만 떨어진 상태는 리셋을 보증하지 않습니다. 소프트웨어 reset은 하드웨어 출력 차단을 대체하지 않습니다.

6. 분리된 STM32H747 SMA 모듈

EasyEDA 회로 초안 · 회로도 보기 · 초안 BOM

2채널 각각 SMA 입력→1kΩ 보호 저항/10MΩ 중간전압 바이어스→입력 버퍼→정합 차동 증폭기→100Ω 및 22pF 피드백→default-ground DPDT mute→SMA 출력입니다. 3개의 OPA2277 듀얼은 두 입력 버퍼, 기준전압 버퍼/정리된 미사용 증폭기, 두 출력 증폭기로 나눴습니다. 기준전압은 별도 J5를 통해 MCU의 실제 VREF+를 받아 절반으로 나눕니다. 외부 MCU나 GPIO는 이 회로에 포함하지 않았습니다.

H747: VDDA=1.8~3.6V, VREF+=1.8V~VDDA. 버퍼 ON 출력은 0.2V~VREF+−0.2V입니다. 3.3V 기준에서 증폭비 100k/14k=7.1429를 사용하여 입력 0.25~3.05V를 ±10V로 변환합니다. SMA 1LSB는 약 5.75mV, INL ±4LSB만 환산해도 약 ±23.02mV입니다. 보정 후에도 16비트 외장 DAC의 분해능을 얻을 수 없습니다. 12비트 전체 monotonic 보증도 아니며 데이터시트는 10비트를 명시합니다.

STM32 DAC의 버퍼 보정(HAL_DACEx_SelfCalibrate 지원 여부를 실제 CubeH7 버전에서 확인), 정상 모드, 양 채널 중간 코드 preload, MCU 초기 출력 차단을 적용합니다. 초기 nominal 제한 코드는 311~3784이지만 실제 VREF와 측정 보정에 맞춰 제한합니다. VREF가 2.5V나 2.048V라면 현재 3.3V 설계의 ±10V 범위를 그대로 적용하지 않습니다.

코액스 케이블을 50Ω 종단하지 않습니다. 수신 보드의 입력 버퍼만으로 MCU 핀의 케이블 용량이 사라지지 않으므로 일반적인 케이블에는 MCU/SMA 송신단에 별도 버퍼를 배치합니다. 간단한 송신단 직렬 저항은 부하·정착·DC 오차를 측정한 경우만 채택합니다. 릴레이는 구체 MPN/접점 핀/풋프린트와 외부 flyback 보호 드라이버가 아직 확정되지 않은 논리적 초안이며 이를 BOM에 명시했습니다.

모듈 아날로그 전원이 꺼진 동안 MCU 입력도 분리/Hi-Z 상태로 만들고, 송신단 버퍼에는 전원 OFF 입력 보호를 적용해야 합니다. 입력 1kΩ만으로 무전원 동작의 적합성을 보증하지 않습니다. 10MΩ 바이어스는 케이블 분리 시 부유 입력을 억제하지만 입력 바이어스 전류 때문에 정확한 0V 출력은 보장하지 않습니다. 케이블 분리 상태는 mute로 처리합니다.

STM32H747 ES0445 Rev.6 §2.11도 초기화에 적용합니다. 해당 실리콘 리비전에서 데이터 레지스터 초기화 전에 MODE를 000 이외 값으로 설정하면 DAC 출력이 잘못될 수 있으므로 데이터 레지스터에 먼저 기록한 뒤 MODE를 설정합니다. 실제 CubeH7/HAL 순서를 확인하고, 출력 mute 상태에서 버퍼 보정·중간 코드 설정·enable·정착 확인을 마친 후 mute를 해제합니다. DMA 사용 시 소프트웨어/하드웨어 트리거를 동시에 쓰는 underrun 플래그 누락 조건도 피합니다. 내부 VREFBUF를 사용하는 경우 §2.12의 잔류 전압에 의한 기동 overshoot와 Hold 모드 제한을 추가 적용합니다. 현재 초안의 기준은 VDDA와 연결된 3.3V VREF+이며, 2.048V/2.5V 내부 VREFBUF용 설계는 아닙니다.

7. 검증 범위와 다음 실행

부품 핀/현재 넷/수식/저항 공차 끝값/제조사 단종 대체품을 확인했습니다. 새 파일은 별도 파서로 핀과 와이어의 실제 좌표, 부유 핀과 다른 넷의 교차를 검사합니다. EasyEDA 자동 가져오기가 완료 결과를 반환하지 않아 실제 가져오기와 ERC는 미확인입니다. TPS65131 기동·LP2985 안정성의 SPICE 또는 실측, 새 모듈의 케이블 과도 해석과 실제 PCB DRC도 아직 수행하지 않았습니다. 시뮬레이션과 실측을 먼저 수행한 후 PCB 한쪽에 새 모듈을 통합합니다. 양·음 레일 전류, 5V 전류, MCU VREF+와 두 출력의 기동/종료 파형을 동시에 측정합니다.

최악 전압을 넘는 STM32 입력 및 DAC 역급전을 우선 해소하고, CP/CN 수정·Q1 대체, 출력 mute/감독 회로, AVDD/증폭비 정밀도 변경을 순서대로 반영합니다. 원본의 과거 DRC 통과 기록은 수정 회로의 검증 결과로 재사용하지 않습니다.

2026-10-12 확인 기준 TPS65131, LP2985, DAC8562T는 제조사 ACTIVE 상태입니다. 단종이 확인된 Q1은 위 대체품을 선정했습니다. 나머지 BOM의 모든 수동소자·커넥터 주문 코드를 제조사 수명주기 문서로 전수 인증한 것은 아니며, 구매 전에 포장 단위·정확한 MPN·재고를 확인합니다. 저항값 변경 부품과 신규 릴레이를 기존 공급사 코드로 위장하지 않고 BOM에 MPN 미확정으로 표시했습니다.
