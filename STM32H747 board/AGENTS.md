# STM32H747 MCU Board 작업 지침

## 작업 범위

- 이 디렉터리 아래의 파일만 수정한다.
- `../TEST_DAC8562`의 파일, 실행 스크립트, 브리지 프로세스, EasyEDA 문서는 수정하거나 실행하거나 중지하지 않는다.
- EasyEDA API로 쓰기 작업을 하기 전에 현재 프로젝트 이름이 `STM32H747_MCU_BOARD_v19`인지 확인한다. 다른 프로젝트가 열려 있으면 즉시 중단한다.

## 기준 자료

- 회로도 기준본: `보드 자료/MCU_BOARD_v19_260827.pdf`
- 구판 비교본: `보드 자료/MCU_BOARD_v19_260616.pdf`
- PCB 제조 참고본: `보드 자료/MCU_BOARD_v19_260616_Gerber/`
- 기구 참고본: `보드 자료/MCU_BOARD.step`
- PDF, Gerber, STEP을 편집 가능한 원본으로 간주하지 않는다.

## 회로도 재작성 규칙

- 사용자의 2026-10-14 변경 요청에 따라 표지/계층 1페이지는 삭제하고, 기준본 2~6페이지를 A3 가로 5페이지로 같은 순서로 만든다.
- 모든 작성 페이지에서 `TECHLABS CO.,LTD` 회사명과 해당 로고를 제외한다. 원본 PDF와 이미 저장된 이력 백업은 보존한다.
- 한 번에 한 페이지만 작성하고, 페이지별 체크포인트를 저장한다.
- 심볼, 핀 번호, 레퍼런스, 값, NC/DNP 상태, 넷 라벨, 버스, 계층 연결을 기준 PDF와 대조한다.
- 시각적 유사성만으로 완료 처리하지 않는다. ERC, 넷 연결, 부품 수, 페이지 간 포트를 함께 검증한다.
- 기존 Gerber는 회로도 넷리스트의 진실 공급원이 아니다. 회로도 최신판보다 오래되었으므로 불일치 가능성을 기록한다.

## PCB 작업 규칙

- 편집 가능한 KiCad/EasyEDA PCB 원본이 없으므로 Gerber에서 임의로 전기적 설계를 복원하지 않는다.
- PCB를 새로 작성할 때는 검증 완료된 EasyEDA 회로도에서 생성하고, Gerber/STEP은 외형·배치·층 구성 비교용으로만 사용한다.
- 제조 파일을 만들기 전 ERC/DRC와 회로도-보드 넷리스트 비교를 수행한다.
- 사용자의 2026-10-15 추가 지시에 따라 현재 선택된 `JLCPCB Capability(Multiple Layers Board)` 규칙에 맞도록 PCB 구리 형상·배선을 수정한다. 규칙이나 검사 범위를 완화하여 통과시키지 않는다.
- 수정 전 전체 체크포인트를 보존하고, 수정 범위·넷 연결·물리 드릴·6층 적층 보존을 검증한다. 기구 가공부 치수 변경은 별도 사용자 답변을 확인한다.
- 사용자는 2026-10-16 CN1 내부 사각 가공부를 1.80×1.80 mm에서 1.92×1.92 mm로 확대하는 것을 명시 승인했다. 이 변경은 기존 사각 중심, Ø1.30 mm 홀, 나머지 외곽·구리·규칙을 유지하고 해당 4변에만 적용한다.
- 설치된 EasyEDA 3.2.206은 Bottom Silkscreen(4) STRING을 자동 반전한다. 정상 뒷면 글자는 추가 `mirror=false`를 사용하고 Gerber 레이어 `isMirror=false`를 유지한다. `mirror=true`는 자동 반전을 상쇄하므로 일반 형식 문서의 설명만으로 판단하지 말고 실제 Gerber의 Y-up/뒷면 투영에서 읽기 방향을 검증한다. 근거: `output/candidates/adc-dc-buffer/installed-pcb-bottom-text-mirror-audit.json`.
- 2026-10-18 현재 J2~J11 전체 10채널 회로도는 ERC/1,136핀·354부품 검증 완료이고 PCB 배치·배선 및 엄격 DRC 0건도 완료했다. 신규 34개 부품 배치, 옛 믹서/바이어스 구리 분리, 10개 MCU 근접 커패시터와 전원/기준전압/접지/신호 배선을 적용했다. 기존 634비아/793드릴을 보존하고 신호 비아 6개만 추가해 640비아/799드릴이다. 6층 적층·18개 규칙·외곽·모서리 홀·CN1·J18을 보존했다. 최신 전체본은 `output/checkpoints/STM32H747_adc10_routed_verified_20261018.epro2`, 실제 DRC는 `output/validation/native-pcb-drc-0ac2a19168000d8e-adc10_routed_reopened_20261018.json`이다. close/open API는 시간 초과 후 재실행하지 않았으며 새 문서 클라이언트에서 실제 소스/DRC를 별도 검증했다. `config/adc-dc-corners-j18-status.md` 상단이 현재 상태이고 아래 202건 WIP 기록은 과거 이력이다.
- 미연결 시 ADC 핀의 실제 0 V 요구는 확정됐지만 검출/출력 선택 회로는 미반영이다. 2026-10-18 사용자는 신호원이 출력 임피던스 50 Ω인 함수발생기이며 주로 60 Hz, 최대 1 MHz 이하임을 확인하고, 남은 PCB 배선·전체 DRC 해결 및 git push를 우선 요청했다. 이번 배선 단계에서는 검증된 10채널 회로도와 대역폭을 임의 변경하지 않는다. 현재 개방은 약 2.5 V이고, 4.68 kHz 전단 필터/채널당 15.6 kS/s는 1 MHz 파형 취득용이 아님을 명확히 기록한다. PCB DRC 완료와 별개로 이 기능 제한 및 기존 내층 Gerber 추가 CAM 검토 전 제조 완료본으로 표시하지 않는다. 계획 JSON과 실제 적용·재개방 증거를 구분하고, 정적 FILL을 전체 재생성하거나 규칙을 완화하지 않는다.
