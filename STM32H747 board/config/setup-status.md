## 남은 PCB 제조 검증

- [ ] 실제 제조사의 간격/공정 조건 확정. 현재 규칙과 비교용 0.10 mm 진단 기준 차이 검토(Gerber Job의 항목별 선언 차이 있음)
- [ ] PCB Clearance Error 2,119건의 규칙·레이아웃 처분 및 최종 DRC 통과
- [ ] 제조사 적층 Dk/Df 및 임피던스 조건 확인
- [ ] 중복 드릴 파일을 제외/구분한 최종 제조 출력과 제조 승인

현재 DRC 2,119건은 모두 양의 간격이며, 0/음수 간격 보고는 없습니다. 비교용 0.10 mm는 균일한 진단 기준일 뿐 Gerber Job의 모든 항목에 적용되는 제조 규칙은 아닙니다. Job의 내층 일부 항목은 0 또는 미기재입니다. 2,078건은 0.10 mm 이상이지만 현재 객체별 제조 규칙에 미달합니다. 41건은 수치상 0.10 mm 바로 아래이며 최솟값은 0.09999853 mm입니다. 원본 재현 범위를 넘어 임의로 규칙을 낮추거나 대규모 재배치하지 않았습니다. 상세 근거는 `output/validation/native-final-clearance-disposition-20261015.json`에 있습니다.

`STM32H747_DIAGNOSTIC_NOT_FOR_FAB.zip`은 검증 전용으로 제조 승인 파일이 아닙니다. `Drill_PTH_Through_Via.DRL`의 634개는 `Drill_PTH_Through.DRL`에도 포함되어 있습니다. 전체 PTH + NPTH 기준 793개 일치가 확인되었지만 중복 파일을 함께 가공 대상으로 지정해서는 안 됩니다. 주문/결제는 하지 않았습니다.

실제 최종 SVG 5페이지의 삭제 요청 영역 제외 3픽셀 허용 오차 비교 결과는 기준 도형 커버리지 100%, 출력 정밀도 99.85~99.96%입니다. NC/DNP 보조 표시의 기본 색상·스타일 차이는 남아 있으며 전기적 상태는 유지했습니다. 따라서 픽셀 단위 완전 동일을 뜻하지 않습니다. PDF 글자는 정적 POLY 벡터이므로 네이티브 값/레퍼런스를 바꾸면 표시 벡터도 별도로 수정해야 합니다. PCB 넷리스트 일치는 실제 구리 연결 DRC 통과와 다른 검증입니다. 제조 준비 완료로 판단하지 않습니다.

`TEST_DAC8562` 작업과 함께 사용할 때는 별도 창을 사용하며, 모든 API 호출에 STM32H747 창 ID와 프로젝트 UUID를 지정합니다. 기존 브리지의 기본 활성 창 선택은 바꾸지 않습니다. 새 프로젝트는 프로젝트가 없는 시작 창에서 로컬 경로로 import한 뒤 별도 editor 창에 열었습니다. 기존 시작 창은 프로젝트가 없는 상태를 유지했습니다.
