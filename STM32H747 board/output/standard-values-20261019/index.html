모두 0402입니다. 재고는 2026-10-19 LCSC 공개 상품 페이지의 확인 시점 수치이며 예약·JLCPCB 실장 재고 확보를 뜻하지 않습니다. 15 kΩ / 9.53 kΩ 대안은 9.53 kΩ의 실제 재고가 0개여서 선택하지 않았습니다. R201은 LCSC 상품 페이지와 EasyEDA 카탈로그가 표시한 400 ppm/K 상한으로 보수적으로 계산했습니다.

회로에 미치는 영향

VADC = 1.6445832 − 0.6965174 × VIN

VIN은 SMA 단자에서 측정한 실제 전압입니다. −2 / 0 / +2 V 입력의 명목 출력은 3.0376 / 1.6446 / 0.2515 V입니다.

두 선은 거의 겹칩니다. 저항 허용오차만 고려한 출력 범위도 0~3.3 V 안에 있습니다. 개방 또는 입력 0 V일 때 ADC는 약 1.645 V입니다. 입력 분리 검출 기능은 추가하지 않았습니다.

R197/R200은 신호 이득을 결정하지 않는 전원 RC 용도입니다. 4.7 Ω, 0.2 W, 100 ppm/K 제품을 선정했습니다. R201의 1.2 Ω은 TI의 저잡음 권장 ESR 1~1.5 Ω 범위에 여유를 두기 위한 값입니다. 1%·400 ppm/K로 −40~85 °C를 계산하면 저항 자체는 약 1.157~1.244 Ω입니다.

이 계산은 이상적인 증폭기와 명목 커패시터를 사용했습니다. 실제 잡음·전원 기동·정착·ADC 전체 오차 검증은 포함하지 않습니다. 펌웨어를 변경하지 않았으므로 기존 보정식을 사용한다면 새 이득과 오프셋을 반영해야 합니다.

실제 저장본 검증

  • 전체 3,941문서 유지. 변경은 03 전원, 06 ADC, PCB의 3개 문서에 한정됐으며 라이브러리는 동일합니다.
  • 회로도와 PCB의 25개 품번·값·공급사 코드·고유 ID 일치. 부품 437개, PAD_NET 1,523개, 비아 704개, 규칙 18개 유지.
  • 6층·100×154 mm 외곽·CN1 가공부·모서리 홀·J18 뒷면 마킹·기존 배선과 라벨 위치 보존.
  • 엄격 PCB DRC 0. ERC는 치명/오류 0, 공급사 속성 불일치 경고 1그룹(R197, R200, R201, R202, R203). 이를 ERC 0으로 표시하지 않았습니다.
  • 새 Gerber의 실제 도형은 이전 검토본과 동일합니다. 내보내기 내부 번호와 같은 색 도형의 출력 순서 변화는 구분해 대조했습니다. 드릴 가공 명령도 동일하며 실제 홀 863개입니다.

이전 CAM의 패드 중심 1,678개 확인 근거는 동일 형상으로 이어집니다. 전체 구리의 전기적 동등성·외부 DFM 승인과는 범위가 다릅니다. PCB는 허용오차 필드를 일부 생략하므로 정확한 허용오차는 회로도와 검토 BOM을 함께 확인합니다.
